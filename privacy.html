Privacy Policy

Effective November 17, 2026

Scope

This policy covers the Monyazone Studio website at monyazone.github.io, including the Orbit Trail browser prototype.

Website and prototype

The site has no sign-in, contact form, advertising, or studio-operated analytics. Its code does not set cookies or write to browser storage. The prototype keeps game progress in memory for the current page session.

Hosting

GitHub Pages hosts the site. GitHub logs visitor IP addresses for security. See the GitHub General Privacy Statement for details on how GitHub handles data.

Email

If you email us, we receive your email address and the information you include. We use that information to respond and follow up. Our email provider processes the correspondence to deliver and store messages.
