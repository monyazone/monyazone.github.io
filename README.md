# Monyazone Studio

Static portfolio for https://monyazone.github.io/. The games section presents four casual game concepts. Privacy Policy and Terms of Service are linked from the footer.

## Preview locally

Open `index.html` in a browser after extracting the ZIP. All styles and images are included.

## Publish on GitHub Pages

1. Copy the extracted files and folders into the root of the publishing branch of `monyazone/monyazone.github.io`.
2. If you previously uploaded an earlier Monyazone Studio package containing `signal-bloom.html`, delete that file and the old `assets/signal-bloom.js`, `assets/signal-bloom.webp`, `assets/tideglass.webp`, and `assets/switchyard-circuit.webp` files from the branch.
3. If necessary, set **Settings → Pages → Deploy from a branch → main → /(root)**. Keep `.nojekyll` in the repository root.
4. When the deployment finishes, open https://monyazone.github.io/ to review the homepage and the two legal pages.
